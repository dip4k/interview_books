## 🎯 **KEY INSIGHTS TAUGHT**

### **Insight 1: The Call Stack is Physical**
Not theoretical—it's an actual 8MB region of memory on Linux. Each function call allocates 24 bytes. At 500,000 calls, you need 12MB > 8MB available. **Crash.**

### **Insight 2: Recursion Trees Show the Real Work**
fibonacci(6) makes 25 function calls to compute 7 unique values. The tree reveals that fib(3) is computed 5 times! Visualization → memoization → 3.5x speedup.

### **Insight 3: Recursion is Tool-Dependent**
- ✅ Trees (depth ≈ 20): Recursion is perfect
- ✅ Graphs (depth ≈ log n): Recursion is perfect
- ❌ Linked lists (depth = n): Iteration is better
- ❌ Linear structures: Never use recursion

### **Insight 4: Memoization Trades Space for Exponential Time**
O(2^n) → O(n) by spending O(n) extra space. For fib(50), this is a 40-quadrillion-times speedup.
