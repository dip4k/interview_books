## 📅 The 8-Week Syllabus

### **Week 1: Foundations & Complexity**

* **Day 1: RAM Model:** How physical memory slots work.
* **Day 2: Big O/Omega/Theta:** Defining upper and lower bounds of efficiency.
* **Day 3: Space Complexity:** Auxiliary vs. Input space.
* **Day 4: Recursion I:** The Call Stack and base case logic.
* **Day 5: Recursion II:** Visualizing recursion trees and relations.

### **Week 2: Linear Structures**

* **Day 1: Arrays:** Static vs. Dynamic (resizing logic).
* **Day 2: Singly Linked Lists:** Pointer mechanics.
* **Day 3: Doubly/Circular Lists:** Bidirectional navigation logic.
* **Day 4: Stacks:** LIFO and expression evaluation logic.
* **Day 5: Queues:** FIFO, Circular, and Deque logic.

### **Week 3: Searching, Sorting & Hashing**

* **Day 1: Binary Search:** The logic of logarithmic elimination.
* **Day 2: Elementary Sorts:** Bubble, Selection, Insertion logic.
* **Day 3: Divide & Conquer:** Merge and Quick Sort (partitioning logic).
* **Day 4: Non-Comparison Sorts:** Counting and Radix sort logic.
* **Day 5: Hashing:** Hash functions and collision handling logic.

### **Week 4: Nonlinear Structures (Trees)**

* **Day 1: Binary Tree Basics:** Hierarchical properties.
* **Day 2: BST:** Search, Insertion, and Deletion logic.
* **Day 3: Traversals:** BFS vs. DFS logic in trees.
* **Day 4: Balanced Trees:** AVL and Red-Black (rotation logic).
* **Day 5: Heaps:** Priority logic and Heapify operations.

### **Week 5: Nonlinear Structures (Graphs)**

* **Day 1: Graph Representations:** Matrix vs. List logic.
* **Day 2: BFS:** Layer-by-layer exploration logic.
* **Day 3: DFS:** Path-based exploration and backtracking logic.
* **Day 4: Connectivity:** Directed vs. Undirected logic.
* **Day 5: Topological Sort:** Dependency resolution logic.

### **Week 6: Advanced Graph Algorithms**

* **Day 1: Dijkstra:** Greedy shortest path logic.
* **Day 2: Bellman-Ford:** Handling negative edge logic.
* **Day 3: MST:** Kruskal’s and Prim’s logic.
* **Day 4: DSU:** Path compression and union-by-rank logic.
* **Day 5: SCC:** Tarjan’s/Kosaraju’s connectivity logic.

### **Week 7: Algorithmic Paradigms I**

* **Day 1: Greedy Choice:** Local optimization logic.
* **Day 2: Two Pointers/Sliding Window:** Buffer management logic.
* **Day 3: Fast & Slow Pointers:** Cycle detection logic.
* **Day 4: Merge Intervals:** Overlap resolution logic.
* **Day 5: Bit Manipulation:** Binary logic and XOR tricks.

### **Week 8: Algorithmic Paradigms II**

* **Day 1: Backtracking:** State-space tree pruning logic.
* **Day 2: DP Intro:** Overlapping subproblems logic.
* **Day 3: DP Approaches:** Memoization vs. Tabulation logic.
* **Day 4: DP Patterns:** Knapsack and LCS logic.
* **Day 5: Advanced DP:** State compression logic.
