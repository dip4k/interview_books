## 📑 Topic Index

### Core Algorithms

**Sorting (6 algorithms covered):**

```
Elementary (O(n²))
├─ Bubble Sort
├─ Insertion Sort
└─ Selection Sort

Efficient (O(n log n))
├─ Merge Sort
├─ Quick Sort
└─ Heap Sort

Hybrid
├─ Timsort (insertion + merge)
└─ Introsort (quick + heap)
```

**Hashing (2 strategies):**

```
Collision Resolution
├─ Chaining (linked lists)
└─ Open Addressing
    ├─ Linear Probing
    ├─ Quadratic Probing
    └─ Double Hashing
```

### Key Concepts

**Complexity Classes:**
- O(n²): Bubble, insertion, selection
- O(n log n): Merge, quick, heap
- O(1 + α): Chaining
- O(1/(1-α)): Open addressing
- Amortized: Resizing

**Data Structures:**
- Heap: Complete binary tree
- Hash table: Array with collisions
- Linked list: Chaining strategy

**Principles:**
- Divide-and-conquer
- In-place sorting
- Stability
- Adaptive algorithms
- Load factor management

## 🗺️ Concept Map

### Week 3 Knowledge Structure

```
SORTING
├─ Elementary Sorts
│  ├─ Bubble (simple, bad)
│  ├─ Insertion (adaptive, good on sorted)
│  └─ Selection (always O(n²))
├─ Efficient Sorts
│  ├─ Merge Sort (O(n log n) guaranteed)
│  ├─ Quick Sort (O(n log n) average, practical)
│  └─ Heap Sort (O(n log n) in-place)
├─ Theory
│  ├─ Master Theorem (predicts O(n log n))
│  ├─ Lower bound (n log n information-theoretic)
│  └─ Stability (preserve equal element order)
└─ Practice
   ├─ Timsort (adaptive hybrid)
   ├─ Introsort (safety-bounded hybrid)
   └─ Database sorting (merge for stability)

HASHING
├─ Fundamentals
│  ├─ Hash function (deterministic, uniform)
│  ├─ Load factor (control collisions)
│  ├─ Birthday paradox (√m items collision)
│  └─ Direct addressing (O(1) lookup)
├─ Collision Resolution
│  ├─ Chaining (simple, slow)
│  │  ├─ Insert O(1 + α)
│  │  ├─ Lookup O(1 + α)
│  │  └─ Delete O(1 + α)
│  └─ Open Addressing (fast, complex)
│     ├─ Linear probing (simple)
│     ├─ Quadratic probing (no clustering)
│     ├─ Double hashing (best)
│     └─ Tombstones (deletion)
└─ Applications
   ├─ Virtual memory (page tables)
   ├─ Compiler symbol tables
   ├─ Database indexes
   └─ CPU caches (TLB)
```

## 🎯 Quick Reference Cards

### Sort Comparison Table

```
Bubble: O(n²) avg, O(n) best, stable, simple
Insertion: O(n²) avg, O(n) best, stable, adaptive
Selection: O(n²) all, unstable, predictable
Merge: O(n log n) all, stable, needs O(n) space
Quick: O(n log n) avg, O(n²) worst, unstable, in-place
Heap: O(n log n) all, unstable, in-place, slow constants
```

### Hash Comparison Table

```
Chaining: O(1+α) avg, simple, deletions OK, O(n) space
Open: O(1/(1-α)) avg, fast, complex deletion, O(n) space
```
