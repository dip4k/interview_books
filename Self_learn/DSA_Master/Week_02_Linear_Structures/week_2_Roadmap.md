## 🛣️ Roadmap — From Week 2 to Upcoming Milestones

### Immediate Next Steps (Week 3: Sorting & Hashing)
1. **Day 1: Elementary Sorts**  
   - Reuse array knowledge to analyze bubble/insertion/selection sort trade-offs.  
   - Focus on algorithmic stability, adaptivity, and when O(n²) sorts are acceptable.

2. **Day 2: Merge Sort & Quick Sort**  
   - Observe divide-and-conquer leveraging recursion (Week 1) + array partitioning (Week 2).  
   - Prepare for quicksort’s partition logic (connect to Week 4.5 Partition pattern).

3. **Day 3: Heap Sort & Variants**  
   - Dynamic array as heap backing; understand parent-child index mapping.

4. **Days 4-5: Hash Tables I & II**  
   - Link arrays and linked lists (chaining) + dynamic arrays (open addressing).  
   - Review load factor management and collision strategies.

### Integration Tasks
- **Reinforce Dynamic Array Knowledge:** Inspect how dynamic arrays underpin `std::vector`, Python list, hash table resizing.  
- **Linked List Application:** Understand when chaining or intrusive lists appear in hash maps / adjacency structures.  
- **Stack & Queue Carryover:** Prepare to use stacks/queues in recursion elimination (quicksort), BFS over sorting buckets.

### Spaced Repetition Targets
- Arrays vs dynamic arrays → revisit before Week 3 hashing (critical for bucket storage).  
- Linked lists → review before Week 4.5 hash map chaining (Tier 1).  
- Binary search → practice for range query problems and to analyze algorithm costs (logarithmic comparisons).

### Mid-Term (Weeks 3–4)
- Transition from foundational structures to **Problem-Solving Patterns** (two-pointer, sliding window).  
- Reinforce queue knowledge through BFS and sliding window max (deque).  
- Prepare for Tier 1 patterns (Week 4.5) — Hash Map, Monotonic Stack, Merge Operations, Partition, Kadane’s.

### Longer-Term Trajectory

- **Week 6+ (Graphs):** Queue for BFS, stack for DFS.  
- **DP (Week 11):** Binary search, arrays, dynamic arrays used for state compression.
