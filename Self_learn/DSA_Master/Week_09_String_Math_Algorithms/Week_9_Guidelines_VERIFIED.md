## 📚 Core Concepts

**Concept 1: Pattern Matching (KMP)**  
O(n+m) via failure function. Preprocessing-based. Avoids redundant comparisons using LPS array.

**Concept 2: Pattern Matching (Rabin-Karp)**  
O(n+m) average via rolling hash. Simple, extends to multiple patterns and 2D grid matching.

**Concept 3: Number Theory**  
Primes, GCD, factorization foundations. Essential for cryptography, hashing, optimization problems.

**Concept 4: Modular Arithmetic**  
Fast exponentiation, modular inverse, CRT. Critical for RSA, Diffie-Hellman, large number operations.

**Concept 5: Computational Geometry**  
Convex hull, point-in-polygon, line intersection. Foundation for graphics, robotics, games.

## ⚠️ Common Mistakes to Avoid

**Mistake 1: "KMP too complex, just use built-in"**
Reality: KMP elegant, O(n+m) guaranteed, interview favorite. Understanding matters.

**Mistake 2: "Hash collisions break Rabin-Karp"**
Reality: Rare with good prime modulus. Always verify string on hash match. Robust when implemented correctly.

**Mistake 3: "Number theory only for cryptography"**
Reality: GCD/LCM for simplifying fractions, LCD. Primes for hashing. Factorization for divisor problems.

**Mistake 4: "Modular arithmetic too hard"**
Reality: Binary exponentiation simple via bit processing. Fermat inverse elegant. CRT advanced but optional.

**Mistake 5: "Geometry not in coding interviews"**
Reality: 2-5% of medium-hard problems. Convex hull classic. Worth learning basics.

## ❓ Frequently Asked Questions

**Q: Is KMP worth memorizing for interviews?**
A: Yes. O(n+m) optimal. Shows deep understanding. Interview classic.

**Q: When use Rabin-Karp over KMP?**
A: Multiple patterns, 2D matching, simplicity preferred. Otherwise KMP default.

**Q: Do I need to memorize all number theory?**
A: GCD and primes essential. Factorization useful. CRT optional (advanced).

**Q: Is modular arithmetic necessary?**
A: For cryptography and large number problems, yes. For general interviews, partial knowledge sufficient.

**Q: How much geometry is tested?**
A: 2-5% of problems. Convex hull most common. Worth learning basics.

**Q: Can I skip any day?**
A: KMP/Rabin-Karp useful (string problems). Geometry can be partial. Number theory essential foundation.
