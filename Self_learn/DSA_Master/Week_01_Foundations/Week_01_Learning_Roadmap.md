## 📅 WEEK 1 SYLLABUS

### Day 1: RAM Model & Pointers
**Duration:** 90 minutes  
**Difficulty:** 🟢 Easy  
**Prerequisites:** None (foundational)  
**Goal:** Understand how computers actually execute programs

**Key Concepts:**
- Von Neumann architecture
- Memory hierarchy (registers, cache, RAM, disk)
- Pointers and memory addresses
- The computational model for algorithm analysis

**Real-World Relevance:**
- Why array access is O(1) but linked list traversal is O(n)
- Why cache misses matter in practice
- How virtual memory works in your OS

---

### Day 2: Asymptotic Analysis
**Duration:** 90 minutes  
**Difficulty:** 🟡 Medium  
**Prerequisites:** Day 1 (RAM Model)  
**Goal:** Learn how to measure algorithm efficiency

**Key Concepts:**
- Big-O notation (upper bound)
- Theta notation (tight bound)
- Omega notation (lower bound)
- How to derive complexity from code
- Why constants matter despite "Big-O"

**Real-World Relevance:**
- Choosing between algorithms by complexity
- Understanding database query performance
- Predicting runtime with different input sizes

---

### Day 3: Recursion I
**Duration:** 90 minutes  
**Difficulty:** 🟡 Medium  
**Prerequisites:** Day 1 & 2  
**Goal:** Master recursion deeply

**Key Concepts:**
- Stack frames and call stack
- Base cases and recursive cases
- Stack unwinding (return values bubbling up)
- Intuitive understanding (not just code)
- Common recursive patterns (linear, tree, exponential)

**Real-World Relevance:**
- Function calls stack in every program
- Tree/graph traversals use recursion
- Understanding stack overflow
- Foundation for dynamic programming

---

### Day 4: Recursion II
**Duration:** 90 minutes  
**Difficulty:** 🔴 Hard  
**Prerequisites:** Day 3  
**Goal:** Master advanced recursion patterns

**Key Concepts:**
- Tail recursion and optimization
- Mutual recursion (functions calling each other)
- Multiple recursive calls (exponential growth)
- Recursion trees and complexity analysis
- When recursion is appropriate

**Real-World Relevance:**
- Mutual recursion in language parsers
- Efficient tail recursion in functional languages
- Understanding exponential blowup in naive solutions

---

### Day 5: Space Complexity
**Duration:** 90 minutes  
**Difficulty:** 🟡 Medium  
**Prerequisites:** Days 1-4  
**Goal:** Understand memory usage and space-time trade-offs

**Key Concepts:**
- Stack vs heap memory
- Recursive depth and stack space
- Memoization vs space usage
- Space-time trade-offs (caching, indexing, etc.)
- Memory leaks and allocation

**Real-World Relevance:**
- Embedded systems with limited RAM
- Database indexing (space for speed)
- Cache sizing and memory management
- Mobile apps with battery constraints
