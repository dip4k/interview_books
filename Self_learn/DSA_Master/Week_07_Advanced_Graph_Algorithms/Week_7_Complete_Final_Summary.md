## 🎓 CURRICULUM HIGHLIGHTS

### Core Algorithms Mastered

1. **Dijkstra's Algorithm** (Day 1)
   - Single-source shortest path
   - Non-negative weights
   - Time: O((V+E) log V)
   - Real-world: GPS, routing

2. **Bellman-Ford Algorithm** (Day 2)
   - Single-source with negatives
   - Cycle detection
   - Time: O(V × E)
   - Real-world: Currency arbitrage

3. **Floyd-Warshall Algorithm** (Day 2)
   - All-pairs shortest path
   - Negative weights allowed
   - Time: O(V³)
   - Real-world: Network analysis

4. **Kruskal's Algorithm** (Day 3)
   - Minimum spanning tree (edge-based)
   - Union-Find optimization
   - Time: O(E log E)
   - Real-world: Network design

5. **Prim's Algorithm** (Day 3)
   - Minimum spanning tree (node-based)
   - Priority queue approach
   - Time: O((V+E) log V)
   - Real-world: Clustering

6. **Ford-Fulkerson/Edmonds-Karp** (Days 4-5)
   - Maximum flow
   - Residual graph & augmenting paths
   - Time: O(V × E²) with BFS
   - Real-world: Routing, matching

7. **Flow Applications** (Day 5)
   - Min-cut & max-flow min-cut theorem
   - Bipartite matching via flow
   - Min-cost max-flow
   - Real-world: Image segmentation, job placement
