## 📖 Reading Order

### Recommended Path: Week-by-Week

Follow this order for maximum learning:

1. **Week 1** → Build foundation (understanding computation)
2. **Week 2** → Learn basic structures (arrays, lists, search)
3. **Week 3** → Master sorting and hashing
4. **Week 4** → Apply techniques to problems
5. **Week 5** → Learn hierarchical structures
6. **Week 6-7** → Master graphs
7. **Week 8-9** → Learn specialized structures
8. **Week 10-11** → Master paradigms (greedy, backtracking, DP)
9. **Week 12** → Integration and interview prep

### Alternative Path: Topic-by-Topic

If you want to skip, this is possible but not recommended:

- **Required:** Week 1 (foundations must come first)
- **Strongly recommended:** Week 2 (all algorithms build on these)
- **Optional after:** Weeks 3-12 can be reordered based on interest

### If Starting Fresh
1. Read README.md (10 min)
2. Read QUICK_START.md (5 min)
3. Open Week_01/01_RAM_Model_Pointers.md
4. Study all 11 sections (90 min)

### If Skipping Week 1
**Don't.** Week 1 is the foundation. All other weeks depend on it.

### If You Know Some Topics
1. Rate your confidence (1-5) for that topic
2. If 4-5: Skip, move to next
3. If 1-3: Study even if you've seen it before (different perspective)

- Focus on Sections 1-7 (Why through Crossovers)
- Sections 8 (Math) can be deferred
- Return to Section 8 later for rigor

- Complete Weeks 1-5 conceptually first
