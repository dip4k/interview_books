## 🧩 COGNITIVE LENSES CONFIGURATION (5 MANDATORY IN SECTION 11)

### Required Format (POINTWISE WITH EMOJIS — UPDATED FOR v5)

**This is the NEW standard format for all cognitive lenses (implemented in Week 3):**

```
## 🧩 5 Cognitive Lenses

**🖥️ Computational Lens**
Focus: [Hardware/performance context]

- **Explanation:** [3-4 sentences on computational costs]
- **Implication:** [How it affects real performance]
- **Practical:** [Real-world optimization strategy]

---

**🧠 Psychological Lens**
Focus: [Misconception/learning context]

- **Common trap:** [Wrong belief students have]
- **Reality:** [Correct understanding with proof]
- **Memory aid:** [How to remember correctly]

---

**🔄 Design Trade-off Lens**
Focus: [Decision/trade-off context]

- **Trade-off 1:** [First competing goal scenario]
- **Trade-off 2:** [Second competing goal scenario]
- **Decision:** [How to choose based on constraints]

---

**🤖 AI/ML Analogy Lens**
Focus: [Modern concept mapping]

- **Analogy:** [Specific analogy to ML/AI concept]
- **Connection:** [How algorithm maps to technique]
- **Insight:** [What you learn from analogy]

---

**📚 Historical Context Lens**
Focus: [Evolution/history context]

- **Origin:** [Inventor, year, motivation]
- **First systems:** [Where it first appeared]
- **Evolution:** [How it evolved over time]
- **Current:** [Modern usage and relevance]
```

### Lens Content Requirements

**🖥️ Computational Lens:**
- RAM model & cache behavior (64-byte cache lines)
- CPU cache levels (L1, L2, L3, RAM latency)
- TLB misses & page faults
- Pointer dereference costs
- Memory allocation patterns
- Branch prediction

**🧠 Psychological Lens:**
- Actual misconceptions students hold
- Why students believe wrong things
- Mental model corrections
- Visual or memorable memory aids
- Common pitfalls

**🔄 Design Trade-off Lens:**
- Memory vs speed trade-offs
- Recursion vs iteration choices
- Simple vs optimized implementations
- Precomputation vs runtime decisions
- Time-space trade-offs

**🤖 AI/ML Analogy Lens:**
- DP ↔ Bellman equation
- Search ↔ inference algorithms
- Gradient descent ↔ greedy algorithms
- Memoization ↔ caching strategies
- Graph algorithms ↔ neural networks

**📚 Historical Context Lens:**
- Inventor name & year
- Original motivation & problem
- First production systems
- Evolution & improvements over time
- Modern variations & usage
- Impact on computer science
