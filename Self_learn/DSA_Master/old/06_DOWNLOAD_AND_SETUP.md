### Problem: Can't Open Markdown Files

**Solution:**
- Use VSCode (recommended)
- Or open with Notepad + enable word wrap
- Or use web-based markdown viewer

### Problem: Files Show Raw Formatting

**Solution:**
- Download a proper markdown editor
- Don't use Microsoft Word (corrupts formatting)
- Don't use Google Docs (changes formatting)

### Problem: Can't Find Files

**Solution:**
- Use file explorer/finder
- Navigate to DSA_Master folder
- Verify all files are there
- Check file extensions (.md)
