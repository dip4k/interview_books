## 🎯 Cross-Week Integration

### Connection to Week 4

**Two Pointers (Week 4 Day 1):**
- Binary search refines similar movement logic
- Both work on sorted data
- Both achieve O(log n) or O(n) with good constants

**Sliding Window (Week 4 Day 2):**
- Binary search can optimize sliding window boundaries
- Complementary, not competitive

**Prefix Sums (Week 4 Day 3):**
- Binary search can search prefix array
- Common combination

**Advanced TP (Week 4 Day 4):**
- Recognition skill carries over
- Techniques work together on complex problems

### Connection to Week 5

**Greedy Algorithms (Week 5):**
- Binary search on answer finds greedy optimal
- Common pairing

**Dynamic Programming (Week 5):**
- Bit manipulation used in bitmask DP
- State compression critical

**Graph Algorithms (Week 5):**
- Binary search on path costs
- Bit manipulation for subset representation
