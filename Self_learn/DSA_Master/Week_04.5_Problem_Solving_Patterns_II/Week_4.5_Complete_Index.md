## 📊 Complexity Reference

### Time Complexity by Technique

| Technique | Best | Average | Worst | Space |
|-----------|------|---------|-------|-------|
| **Binary Search** | O(log n) | O(log n) | O(log n) | O(1) |
| **Bitwise Ops** | O(1) | O(1) | O(1) | O(1) |
| **Integration** | Varies | Varies | Varies | Varies |

### When to Use Each

```
Binary Search:
  ✓ Sorted data, find element
  ✓ Answer forms searchable range
  ✓ Need O(log n) time

Bit Manipulation:
  ✓ Flags/permissions
  ✓ Space critical
  ✓ Performance critical

Integration:
  ✓ Multiple constraints
  ✓ Single technique insufficient
  ✓ Synergistic combination
```
